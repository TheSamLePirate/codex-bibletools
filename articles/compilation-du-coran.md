# Compilation du Coran

**Islam.** Volonté de compiler le Coran car trop de récitateurs mourraient pendant les guerres [bukhari:4986](https://pascatho.ovh/?bukhari%3A4986) Une forme de divergence entre Hafsa et Uthman sur d'éventuelles versions différentes du manuscrit [bukhari:4987](https://pascatho.ovh/?bukhari%3A4987) Déjà à l'époque, la véracité des écrits n'était pas établie puisqu'il dit : "Si vous n'êtes pas d'accord avec Zaid bin Thabit sur n'importe quel point du Coran, puis écrivez-le dans le dialecte du Coran, le Coran a été révélé dans leur langue."
